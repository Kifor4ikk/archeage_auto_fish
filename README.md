<h2>Main idea</h2>
First of all it is not only for archeage.
This is about recognizing pictures on ur screen and press buttons.
Main idea was to use it in ArcheAge game to simplify fishing.
<h2>How to use it?</h2>
First of all u need to install Python 3.11.0
<a href=https://www.python.org/ftp/python/3.11.0/python-3.11.0-amd64.exe>Link to download 64 bit installer</a>
<a href=https://www.python.org/downloads/release/python-3110/>Python site</a>
1: Execute start.bat as administrator.
2: When it will open choose point 1 "Create new zone".
3: Name it and give it a stop button. You can write smth like "SHIFT+F12" and use double keys
4: After u should calibrate zone. Set monitor, Set zone to find a picture of buff.
5: After u shld add "keybinds".json file which contains image and button for this image.
6: You can change threshold and delay between pressing. Default is 0.7 and 4s.
7: After saving zone do not forgot to SAVE this all choosing point 3 in main menu.
8: After choose point five and write active button to activate some zone.
<img width="569" height="119" alt="image" src="https://github.com/user-attachments/assets/a26f6777-66cb-4da5-bb43-b68077a7bb21" />
9: Zone will be activated untill u dont press keys to disable it.
10: Enjoy!

<h2>Главная идея.</h2>
В первую очередь это не только для АрчКека.
В целом данная прила о распознании картинки на экране и нажатие соответствующей кнопки в ответ.
Но главной целью была автоматическая рыбалка в АрчКеке.
<h2>Как пользоваться?</h2>
В первую очередь качаем и устанавливаем Python 3.11.0 
<a href=https://www.python.org/ftp/python/3.11.0/python-3.11.0-amd64.exe>Прямая ссылка на скачивание 64 битного установщика</a>
<a href=https://www.python.org/downloads/release/python-3110>Официальный сайт Петухона 3.11</a>
1: Запускаем start.bat от имени администратора.
2: Если всё запустилось с кайфом, то выбираем пункт 1 для создания новой зоны.
3: Даём название и кнопку (можно сочетание клавиш "SHIFT+F12" которую будем использовать для выключения активности.
4: После создания зоны открывается меню калибровки зоны. Тут нужно выбрать монитор(пункт 1), на котором происходит действие. И пункт 2 "Выбрать зону на которой будет искаться картинка".
5: После нужно указать "клавиши".json - файл в котором описаны названия картинок и соответствующие клавиши для нажима.
6: После можно выбрать порог значения распознавания картинки, (но лучше не трогайте), а так же время задержки между нажатиями клавиши при расспознании картинки. (По умолчанию 0.7 и 4с)
7: После сохраняем зону и не забываем СОХРАНИТЬ ЕЁ В ГЛАВНОМ МЕНЮ ПОСРЕДСТВОМ ВЫБОРА ПУНКТА 3.
8: Выбирая пункт 5 ВВОДИМ клавиши которые вы указали при создании зоны.
<img width="569" height="119" alt="image" src="https://github.com/user-attachments/assets/a26f6777-66cb-4da5-bb43-b68077a7bb21" />
9: Всё будет работать до момента нажатия на сочетания ваших клавиш (при  учете, если других проблем не произошло)
10: Наслаждаемся!

<h2>Main idea</h2>
First of all it is not only for archeage.<br>
This is about recognizing pictures on ur screen and press buttons.<br>
Main idea was to use it in ArcheAge game to simplify fishing.<br>
<h2>How to use it?</h2><br>
First of all u need to install Python 3.11.0<br>
<a href=https://www.python.org/ftp/python/3.11.0/python-3.11.0-amd64.exe>Link to download 64 bit installer</a><br>
<a href=https://www.python.org/downloads/release/python-3110/>Python site</a><br>
1: Execute start.bat as administrator.<br>
2: When it will open choose point 1 "Create new zone".<br>
3: Name it and give it a stop button. You can write smth like "SHIFT+F12" and use double keys<br>
4: After u should calibrate zone. Set monitor, Set zone to find a picture of buff.<br>
5: After u shld add "keybinds".json file which contains image and button for this image.<br>
6: You can change threshold and delay between pressing. Default is 0.7 and 4s.<br>
7: After saving zone do not forgot to SAVE this all choosing point 3 in main menu.<br>
8: After choose point five and write active button to activate some zone.<br>
<img width="569" height="119" alt="image" src="https://github.com/user-attachments/assets/a26f6777-66cb-4da5-bb43-b68077a7bb21" /><br>
9: Zone will be activated untill u dont press keys to disable it.<br>
10: Enjoy!<br>

<h2>Главная идея.</h2><br>
В первую очередь это не только для АрчКека.<br>
В целом данная прила о распознании картинки на экране и нажатие соответствующей кнопки в ответ.<br>
Но главной целью была автоматическая рыбалка в АрчКеке.<br>
<h2>Как пользоваться?</h2><br>
В первую очередь качаем и устанавливаем Python 3.11.0 <br>
<a href=https://www.python.org/ftp/python/3.11.0/python-3.11.0-amd64.exe>Прямая ссылка на скачивание 64 битного установщика</a><br>
<a href=https://www.python.org/downloads/release/python-3110>Официальный сайт Петухона 3.11</a><br>
1: Запускаем start.bat от имени администратора.<br>
2: Если всё запустилось с кайфом, то выбираем пункт 1 для создания новой зоны.<br>
3: Даём название и кнопку (можно сочетание клавиш "SHIFT+F12" которую будем использовать для выключения активности.<br>
4: После создания зоны открывается меню калибровки зоны. Тут нужно выбрать монитор(пункт 1), на котором происходит действие. И пункт 2 "Выбрать зону на которой будет искаться картинка".<br>
5: После нужно указать "клавиши".json - файл в котором описаны названия картинок и соответствующие клавиши для нажима.<br>
6: После можно выбрать порог значения распознавания картинки, (но лучше не трогайте), а так же время задержки между нажатиями клавиши при расспознании картинки. (По умолчанию 0.7 и 4с)<br>
7: После сохраняем зону и не забываем СОХРАНИТЬ ЕЁ В ГЛАВНОМ МЕНЮ ПОСРЕДСТВОМ ВЫБОРА ПУНКТА 3.<br>
8: Выбирая пункт 5 ВВОДИМ клавиши которые вы указали при создании зоны.<br>
<img width="569" height="119" alt="image" src="https://github.com/user-attachments/assets/a26f6777-66cb-4da5-bb43-b68077a7bb21" /><br>
9: Всё будет работать до момента нажатия на сочетания ваших клавиш (при  учете, если других проблем не произошло)<br>
10: Наслаждаемся!<br>
